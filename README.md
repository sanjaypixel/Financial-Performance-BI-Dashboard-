# Financial-Performance-BI-Dashboard-

Project Overview

This project presents an end-to-end Financial Business Intelligence Dashboard built using .
The dashboard analyzes key financial metrics such as Sales, Profit, and Discounts across different countries, products, and customer segments.

The goal is to transform raw financial data into actionable insights for better business decision-making.

Objectives

Analyze overall financial performance
Identify top-performing products and regions
Understand the impact of discounts on profitability
Track sales trends over time
Enable interactive filtering using slicers


Relationships:
One-to-Many (1:*) from Dimension → Fact
Single-direction filtering

Data Preparation
Cleaned and transformed data using Power Query
Created a Date Table using DAX
Removed duplicates in dimension tables
Established proper relationships

Key Measures (DAX)
Total Sales
Total Profit
Profit Margin
Sales by Discount Band
Dashboard Features
 Sales Trend (Time Series)
 Sales & Profit by Country
 Product Performance Analysis
 Segment-wise Distribution
 KPI Cards (Sales, Profit, Units Sold)
 Interactive slicers (Year, Country, Segment)

Key Insights
High discounts increase sales but reduce profitability
Certain countries contribute higher revenue but lower margins
A few products drive the majority of profits (Pareto effect)

Tools & Technologies

Power Query
DAX (Data Analysis Expressions)

Conclusion
This dashboard demonstrates how financial data can be effectively modeled and visualized to uncover business insights.
It highlights the importance of data modeling, DAX calculations, and storytelling in Business Intelligence.
